# pos-puc-mvp-pipeline-de-dados-na-nuvem
Desenvolvimento de um pipeline para o MVP de Engenharia de Dados com o tema Pipeline em Nuvem com Databricks

## 1. Contexto de Negócio e Problema
Descrição: O objetivo deste projeto é construir um pipeline de dados de ponta a ponta na nuvem para analisar o desempenho comercial de um marketplace de e-commerce. Pretende-se compreender os fatores que impactam a receita, o comportamento de compra dos clientes e a eficiência logística das entregas, transformando dados brutos em indicadores acionáveis para a tomada de decisão.

## 2. Perguntas de Negócio
Para guiar todo o processo de engenharia, transformação e modelagem no Data Lakehouse, o pipeline foi desenhado para responder às seguintes questões:
### 1. Qual é a categoria de produto que gera a maior receita total para a empresa?
### 2. Existe uma correlação evidente entre o valor do frete pago e o tempo de entrega para diferentes regiões geográficas?
### 3. Qual é o ticket médio das compras agrupadas por método de pagamento utilizado pelos clientes?

## 3. Origem e Licença dos Dados Brutos
#### Fonte: Brazilian E-Commerce Public Dataset (obtido através do repositório público do Kaggle).
#### Estruturação dos Dados Brutos: O conjunto de dados é composto por ficheiros em formato .csv que contemplam informações transacionais de pedidos, registos de clientes, detalhes de produtos, valores de frete, preços e formas de pagamento.
#### Licença de Uso: Dados disponibilizados sob licença aberta para fins educacionais e de portfólio, em conformidade com as diretrizes de utilização de dados abertos especificadas na plataforma de origem.
